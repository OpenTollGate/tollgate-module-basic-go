- **The upstream portal poke fires only for validated TollGates, once.** The TEMPORARY captive-portal workaround (`TriggerCaptivePortalSession` — a browser-mimicking GET to the upstream gateway's port 80, expressly outside the TollGate protocol) used to fire from inside the probe path: any HTTP 200 from gateway `:2121` earned the poke — before the advertisement was validated, again on every 30 s detector tick, forever, for gateways the module had already rejected as non-TollGates. Bench evidence: a pristine rc1 VM whose slirp upstream carried an unrelated mock service on `:2121` poked `gateway:80` every cycle with no payment and no accepted advertisement. It now fires only from `HandleGatewayConnected`, after `ValidateAdvertisementFromBytes` accepts the gateway's advertisement, at most once per gateway per process ([#768](https://github.com/OpenTollGate/tollgate-module-basic-go/issues/768)).
