- **A machine-readable build contract.** `packaging/build-contract.json` (generated by `scripts/gen-build-contract.sh`, never hand-edited) declares the release's facts once — binary set, module map, ldflags profiles, language minimum, pinned toolchain and portal commit — so downstream feeds read them from the release tarball instead of re-deriving by hand, and `tests/contract/check-build-contract.py` fences every carrier to ship the full binary set (the #1020 class: a binary added to the authority but missed by a carrier now fails at commit time). `repro-test T=binaries` covers all three artifacts.
