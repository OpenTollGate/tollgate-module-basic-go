- **Per-mint payment method for custom-unit mints.** Custom-unit issuance derived the mint's payment method from the *unit* and fell back to a hardcoded `"paypal"` — a bench-harness stub promoted to a shipped default. Against an operator mint whose processor registers any other name (Pecan registers `branch`) every issuance quote addressed a method the mint does not have, so issuance could never succeed; and because it was a per-process environment variable, one router could not front a counter-settled mint and a bolt11 mint at the same time. The method is now declared per mint as `accepted_mints[].payment_method`, an unconfigured custom-unit mint is refused with an actionable error instead of sent to a guess, and a sat mint is unaffected (empty means the unit's default). ([#1150](https://github.com/OpenTollGate/tollgate-module-basic-go/pull/1150))
- **The `cdk_wallet` build tag compiles again.** The tag-gated backend — the only path that supports custom units — had not compiled: a probe called `Wallet.ActiveKeyset()`, which this module's pinned cdk-go does not have (it is `FetchActiveKeyset()` returning `KeySetInfo`). Because the tag is not part of the default battery, the failure was invisible. The probe now uses the pinned API, so `go vet -tags cdk_wallet ./...` is clean. ([#1150](https://github.com/OpenTollGate/tollgate-module-basic-go/pull/1150))
