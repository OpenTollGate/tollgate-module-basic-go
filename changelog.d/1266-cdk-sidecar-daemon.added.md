- **The CDK sidecar daemon: the other end of a socket that had nobody on it.** `select.go` has routed a `cdk`/`sidecar` wallet backend to `NewSidecarWallet` for a while, and nothing served that socket, so the CDK backend was unreachable. `SidecarDaemon` now answers the sidecar protocol over AF_UNIX by adapting the already-tested `CdkWallet`; no money logic lives in the daemon. It exists as a separate process because cdk-go reaches libcdk through cgo FFI, and `CGO_ENABLED=0` fails at `cashubtc/cdk-go/bindings/cdkffi` for mipsle and arm64 — the router binary must stay pure Go for every OpenWrt target. Requests are serialised through one mutex (the wallet is single-writer), the socket is created `0600` because it controls money, a malformed line is answered and its connection ended rather than killing the daemon, and a client-sent stop request is ignored so no local caller can halt the wallet mid-transaction. ([#1266](https://github.com/OpenTollGate/tollgate-module-basic-go/pull/1266))
