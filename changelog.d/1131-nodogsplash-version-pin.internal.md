- **The captive-portal daemon is a pinned version now, per OpenWrt era, with a fence that fails.** `nodogsplash` was the last unversioned external input: `packaging/Makefile` declared `DEPENDS:=+nodogsplash`, and nothing in the tree named which build of it an operator's router would run, so a feed bump silently changed the shipped daemon — the binary every gate, session and pre-auth allow-list here was bench-verified against. `packaging/build-inputs.json` gains `.nodogsplash.per_era` pinning `PKG_VERSION` + `PKG_RELEASE` + `PKG_HASH` for both lanes (`tests/contract/check-nodogsplash-pin.py`). It is per-era because the eras genuinely resolve different packaging releases of the same upstream version — apk `5.0.2-r2` (25.12, the only feature target) vs ipk `5.0.2-r1` (≤24.10, frozen compatibility) — so a single-value pin would be a false equality that names a package one lane does not publish and passes anyway. Three legs refuse drift: glob-discovered carrier identity (a carrier stating `5.0.2-r2` is refused on the ipk lane), the live feed recipe per era, and a built artifact's own dependency metadata; `tests/contract/nodogsplash-pin_test.sh` plants every drift shape and requires the refusal by name, per AGENTS.md rule 4. No version changed, nothing vendored — this NAMES the version; PRTA's `nds_dependency_identity` is what will PROVE it. ([#1131](https://github.com/OpenTollGate/tollgate-module-basic-go/pull/1131))
