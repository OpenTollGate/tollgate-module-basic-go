- Boot now refuses to start (hard error, config file left untouched) when `accepted_mints` is present in an otherwise well-formed config but its entries do not parse as mint objects — e.g. the plain string array `["https://mint.example"]`. Previously this was treated as wholesale config corruption: the operator's file was backed up and rewritten with factory defaults, silently swapping the money path to the seven built-in public mints. Genuinely unparseable (truncated) documents keep the backup-and-defaults recovery. ([#931](https://github.com/OpenTollGate/tollgate-module-basic-go/pull/931))
