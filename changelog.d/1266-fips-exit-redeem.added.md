- **Admission now requires a verified claim, not a line in a file.** `fips_exit.Redeem` composes the claim layer with the admission ledger, so a purchase becomes an entitlement only when the buyer proves key possession, the claim arrived over the buyer's own tunnel, the nonce has not been seen, and the grant window and billing mode match what the challenge priced. `fips-exitd` admits on clients-file presence alone, so whatever writes that file is the admission authority; this makes that authority refuse a claim it cannot verify.
