- **A purchase endpoint the exit can actually serve.** `fips_exit.PurchaseService` answers `GET /` with priced challenge terms and `POST /` with a signed-claim purchase, so a buyer can discover terms and buy before any forwarding is granted. `fips-exitd` speaks raw IPv6 only and the module':2121 identifies callers by DHCP MAC, which a remote FIPS peer never has; this listener binds the purchase to the transport's own source address instead, and writes the daemon's clients file through the same `Apply` the reconciler uses.
