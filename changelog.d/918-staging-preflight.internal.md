- **The SDK package build refuses unclear inputs by name instead of failing inside the container.** Building a package without the portal bundle staged, with a truncated staging copy, or into a shared unwritable portal tree now aborts in seconds with the exact remediation (`make portal-build`, disk-full path, private `PORTAL_DIR`); the portal bundle is rebuilt automatically from the pinned tree when missing or stale, and the portal working tree defaults to a per-checkout `.portal-tree` instead of a shared `/tmp` path ([#918](https://github.com/OpenTollGate/tollgate-module-basic-go/pull/918)).
